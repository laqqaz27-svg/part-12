Full Stack Open — Part 12, Exercise 8: Mongo CLI

Command used to access MongoDB:

```bash
docker exec -it todo-backend-mongo-1 mongosh -u root -p example --authenticationDatabase admin
```

MongoDB shell session:

```text
test> use the_database
switched to db the_database

the_database> show collections
todos

the_database> db.todos.insertOne({
    text: "Increase the number of tools in my tool belt",
    done: false
})
{
  acknowledged: true,
  insertedId: ObjectId('6adefe79c4fbdee2f51593dc')
}

the_database> db.todos.find({
    text: "Increase the number of tools in my tool belt"
})
[
  {
    _id: ObjectId('6adefe79c4fbdee2f51593dc'),
    text: 'Increase the number of tools in my tool belt',
    done: false
  }
]

the_database> exit
```
