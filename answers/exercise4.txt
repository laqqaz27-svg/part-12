Exercise 4: Ubuntu 102

Started the existing Ubuntu container:
docker start -ai exercise2-ubuntu

Updated package lists:
apt-get update

Installed curl:
apt-get install -y curl

Checked curl:
curl --version

Installed Node.js 24:
curl -sL https://deb.nodesource.com/setup_24.x | bash
apt-get install -y nodejs

Checked Node.js:
node --version

Checked npm:
npm --version

Ran the JavaScript file:
node /usr/src/app/index.js

Output:
Hello World

Exited the container:
exit
